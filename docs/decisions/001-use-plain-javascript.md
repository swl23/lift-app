# 1. Use plain JavaScript

Date: 2026-11-12\

## Context

I want to use this project to get some additional practice with React as well as
overall system design on this project. While I understand TypeScript adds type
safety, it's one more thing than I am looking to focus on at this time, having
no experience with it currently.

## Decision

Write the app in plain JavaScript for now.

## Alternatives considered

- TypeScript from the start - alas, just too many new things at once.

## Consequences

- Able to get started faster on refining the app's core logic with tools I
  already know.
- Bugs that TypeScript could catch might slip through, but consistent testing
  will help cover this.
- Will plan to revisit issue later: refactoring my JS to TypeScript could pose a
  good learning opportunity.
