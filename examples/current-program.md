# Current program

Snapshot of the split as I actually run it, taken 2026-11-12. This is the real
data the Phase 1 data model is checked against.

## Structure

- 4-day rotation: Upper 1 → Lower 1 → Upper 2 → Lower 2, then repeat.
- All weights in lb.

## Default progression (double progression)

Applies to every lift with a rep range:

1. Every set uses the same weight and the same rep target, starting at the bottom
   of the range.
2. Hit the target on all sets: add 1 rep to each set next time.
3. Hit the top of the range on all sets: add weight next time and drop back to the
   bottom of the range.

Open questions: how much weight gets added, and what happens after a missed set.

## AMRAP lifts

AMRAP lifts have no automatic progression. I log the reps I got on each set,
and I change the weight by hand when I decide to.
